# 🥗 Nutrition Meter App (Gemini Pro)

## 📌 Overview
The **Nutrition Meter Application** leverages advanced AI to analyze the nutritional content of meals using images. Users can simply upload a food image to receive detailed insights into calories and macronutrient composition.

This tool is designed to help users maintain a balanced diet by offering actionable health insights and recommendations.

---

## 🚀 Key Features

### 🔍 Nutritional Analysis
- Detects food items from uploaded images  
- Calculates total calorie intake  
- Provides a detailed breakdown of:
  - Proteins  
  - Carbohydrates  
  - Fats  

### 📊 Health Monitoring
- Evaluates the healthiness of meals  
- Suggests nutritional improvements  
- Helps users track dietary habits  

---

## 🛠️ Technology Stack

- **Streamlit** – Interactive web interface  
- **Pillow (PIL)** – Image processing  
- **dotenv** – Environment variable management  
- **Google Generative AI (Gemini Pro)** – AI-powered nutritional analysis
